# Wi-Fi Troubleshooting
1. Confirm Wi-Fi is enabled and airplane mode is off.
2. Check whether other devices can connect to the same network.
3. Forget and reconnect to the approved corporate Wi-Fi network.
4. Restart the Wi-Fi adapter or device if permitted by company policy.
5. If the issue continues, create an IT ticket with the network name, approximate time, and error message. Never send Wi-Fi passwords in a ticket.
